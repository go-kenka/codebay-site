常见问题

会改动我的会话文件吗？

不会。CodeBay 只读索引各 Agent 的原生会话文件，不复制、不改写；会话的创建与清理由各 CLI 自己负责。

会上传我的会话或代码吗？

默认不会：没有账号、没有遥测。只有你主动使用内置 AI 功能（例如改写提示词、生成提交信息）或从链接导入插件时，才会连接你自己配置的地址。

支持哪些 Agent？

内置 Claude Code、Codex、OpenCode、DeepSeek、OMP、Pi；其他 Agent 可以用一份插件 JSON 接入，添加前会在本机实测。

多个 Agent 并行会不会互相覆盖？

不会。CodeBay 用一个分支一份 Git worktree 隔离并行会话；跨仓库任务还可以组成「工作树组」，共用一条分支和同一个目录。

从 Finder 启动，找不到 claude 命令怎么办？

CodeBay 会合成登录 shell 的 PATH，并补上常见安装目录，从 Finder 启动也能找到。

已经被清理的会话还能恢复吗？

无法恢复。CodeBay 会把它标成不可恢复并说明原因，而不是启动一个注定失败的进程。

没有 Apple 签名，怎么安装？

预览版是 ad-hoc 签名，macOS 会提示“无法验证开发者”。安装后在 Finder 里右键 CodeBay →「打开」即可；也可以使用 install.sh，它会按芯片选择 Apple Silicon 或 Intel 安装包，下载、校验、ad-hoc 签名并安装到 ~/Applications。这只是测试版的分发方式，不等于正式签名。
